# Nobcoder Full Portable Security Stack

This archive is the public, credential-free portable snapshot of the security
research stack built through 2026-11-03.

It includes:

- shared and installed Codex skills, prompts, and agent instructions;
- security reference catalogs and PayloadsAllTheThings reference material;
- Codex Security Harness source history, evaluation, and governance packages;
- V0.2 and V0.3 engineering workspaces and frozen evidence through Roadmap 10
  First Real Security Worker V35;
- runtime compatibility, contracts, schemas, tests, methodology labs, runtime
  blueprints, audit stacks, tooling definitions, and portable stack sources.

It intentionally excludes credentials and host-specific/private state:

- `auth.json`, `.env`, private keys, tokens, and credential stores;
- Git object databases, virtual environments, package caches, and
  `node_modules`;
- browser profiles, shell histories, cloud/SSH/GPG configuration, and private
  target reports;
- installed toolchain/database payloads and raw 14 GB pilot-run sessions.

The excluded runtime/toolchain material is not required to preserve the
project's authored source, contracts, governance, skills, and frozen Roadmap 10
evidence. Reinstall dependencies on the destination laptop rather than copying
host-bound credential or runtime state.
